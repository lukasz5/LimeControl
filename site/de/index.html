Funktionen der App

Alles, was Sie im Feld und unterwegs brauchen

Die häufigsten Umfrage-Aufgaben — nur ein paar Tipps entfernt, auf jedem Gerät.

Mehrere LimeSurvey-Instanzen

Legen Sie für jeden Server ein Profil an und wechseln Sie mit einem Tippen. Nach der Anmeldung mit einem Google-Konto werden die Profile in der Cloud synchronisiert.

Umfragen aktivieren und beenden

Aktivieren Sie eine Umfrage samt Token-Tabelle, setzen Sie die Daten startdate und expires, beenden Sie eine Studie oder kopieren Sie eine Umfrage.

Serverseitiger Zeitplaner

Planen Sie eine Aktivierung, das Beenden einer Umfrage, einen Einladungsversand oder wiederkehrende Erinnerungen. Der Auftrag läuft auf dem Server — auch wenn Ihr Smartphone aus ist.

Vorlagenbibliothek

Importieren Sie einen fertigen Fragebogen mit einem Tippen in die verbundene Instanz — vom NPS bis zum CATI-Interviewgerüst. Sie erhalten eine inaktive Umfrage, die Sie frei anpassen können.

Link, QR-Code und Design

Kopieren oder teilen Sie den Umfragelink, zeigen Sie einen QR-Code für Plakat oder Folie und legen Sie das Design der Umfrage fest — ohne das Admin-Panel zu öffnen.

CAPI-Modus

Starten Sie ein Interview auf Tablet oder Smartphone und schalten Sie die Interview-Schleife ein: Endet ein Interview, beginnt die Umfrage von selbst das nächste, leere.

Teilnehmer und Einladungen

Befragte hinzufügen und entfernen, E-Mail-Vorlagen mit Live-Vorschau bearbeiten, Einladungen und Erinnerungen versenden — sofort oder über den Zeitplaner.

Statistiken und Vergleiche

Eine Übersicht über Antworten und Tokens als Diagramme und zwei Umfragen im direkten Vergleich — alles aus get_summary.

Antwortexport

Laden Sie Antworten als CSV, Excel oder JSON herunter und schlagen Sie Spaltenbezeichner (SGQA und LS 7) im get_fieldmap-Inspektor nach.

Benachrichtigungen und RPC-Protokoll

Meldungen zu erledigten und fehlgeschlagenen Aufträgen, eine Ansicht jedes JSON-RPC-Aufrufs mit Antwortzeit, CORS-Diagnose und verständliche API-Fehler.

Mobile App und PWA

Eine kostenlose, native App für iPhone, iPad und Android — ohne Konto. Kostenlos erhältlich: Google Play. Die Version im App Store wartet noch auf die Veröffentlichung. Im Browser können Sie LimeControl als PWA zum Startbildschirm hinzufügen.

Eigener Server, keine Cloud

Betreiben Sie LimeControl in einem Docker-Container und melden Sie sich mit einem Zugangsschlüssel an — ohne Google-Konto; Relay und Zeitplaner laufen in Ihrem Netz.

So funktioniert’s

In vier Schritten startklar

Auf dem LimeSurvey-Server installieren Sie nichts — eine aktivierte JSON-RPC-API genügt.

  1. API in LimeSurvey aktivieren

    Konfiguration → Globale Einstellungen → Schnittstellen und JSON-RPC wählen.

  2. Anmelden

    LimeControl öffnen und mit einem Google-Konto anmelden. In der eigenen Installation genügt ein Zugangsschlüssel, in der mobilen App braucht es gar kein Konto.

  3. Instanz hinzufügen

    LimeSurvey-Adresse, Benutzername und Passwort eingeben. Der API-Pfad wird automatisch ergänzt.

  4. Verwalten

    Umfragen aktivieren, Vorlagen importieren, Versand planen und Ergebnisse herunterladen.

CATI und CAPI

Telefon- und Face-to-Face-Interviews mit LimeSurvey

Die kostenlosen LimeControl-Werkzeuge machen eine Umfrage interviewertauglich: ein komfortables Design, ein fertiges Interviewgerüst und ein Modus „Interview nach Interview“. Braucht eine Studie Zuteilungen, eine Anrufwarteschlange, Telefonie und Quoten, ergänzen Sie die kostenlosen Plugins und ein Konto auf der Plattform StrefaAnkiet — und verfolgen den Feldfortschritt in der App.

Kostenlose StrefaAnkiet-Plugins So führen Sie Interviews
  • CATI-Design — ein Layout für Interviewer am Computer: Antworten mit den Tasten 1–9, nächste Seite mit Strg+Enter, Navigation immer griffbereit.
  • CAPI-Design — große Touch-Flächen und klare Typografie für Tablet oder Smartphone im Feld.
  • Interviewgerüste — die Vorlagen „CATI-Interview“ (Kontaktergebnis, Rückrufzeit, Interviewernotiz) und „CAPI-Interview“, auf Englisch und Polnisch.
  • Interview-Schleife — die App richtet die Umfrage so ein, dass nach jedem Interview automatisch das nächste beginnt; Link und QR-Code für den Interviewer sind griffbereit.
  • Feldstatus aus StrefaAnkiet — abgeschlossene Interviews, Interviewer-Zuteilungen und die Anrufwarteschlange direkt bei der Umfrage, nur lesend (Beta).

Sicherheit und Datenschutz

Ihre Passwörter bleiben bei Ihnen

Im Direktmodus spricht LimeControl direkt aus dem Browser mit Ihrem Server — Umfragedaten laufen nicht über unsere Server, und LimeSurvey-Passwörter werden nicht in den Profilen gespeichert.

So schützen wir Daten
  • LimeSurvey-Passwörter gelangen nie in die Cloud — weder in Firestore noch in localStorage. Optional bleiben sie nur im Speicher des geöffneten Tabs.
  • Direkte Verbindung vom Browser zu Ihrem Server über HTTPS. Das Server-Relay schalten Sie nur bei Bedarf ein.
  • Das Relay ist nur für angemeldete Nutzer — mit Anfragelimit und, im öffentlichen Dienst, gesperrten internen Netzadressen.
  • Der Zeitplaner verschlüsselt das Auftragspasswort (AES-256-GCM) und löscht es, sobald der Auftrag gelaufen ist oder abgebrochen wurde.
  • Der Code ist offen — Sie können ihn prüfen oder die App auf Ihrem eigenen Server betreiben.
FAQ

Häufige Fragen

Ist LimeControl kostenlos?

Ja. App, Designs, Umfragevorlagen, Plugins und Deployment-Kits sind kostenlos — ohne Begrenzung bei Umfragen oder Instanzen. Wenn sie Ihnen nützen, können Sie die Weiterentwicklung über den Link „Spendier mir einen Kaffee“ in der Fußzeile unterstützen.

Was ist dann kostenpflichtig?

Dienste. Ein StrefaAnkiet-Konto liefert, was Software allein nicht kann: verwalteten Versand über Amazon SES, VoIP-Telefonie für CATI-Interviews, Interviewer im Feld sowie Analysen und Berichte. Separat bieten wir Einrichtung und Betreuung von Umfrageservern an. Die kostenlosen Werkzeuge funktionieren ohne jeden dieser Dienste.

Ist LimeControl Open Source?

Ja. Der Code der App, der Umfrage-Designs und der Deployment-Kits liegt auf GitHub unter GPL-2.0-or-later, die Umfragevorlagen stehen unter CC0. Auch die StrefaAnkiet-Plugins für LimeSurvey sind Open Source. Fehlerberichte und Pull Requests sind willkommen. Inhalt und Gestaltung dieser Website gehören nicht zum Open-Source-Code.

Gibt es die App auf Deutsch?

Die Oberfläche der App ist derzeit auf Englisch und Polnisch verfügbar, ebenso die Umfragevorlagen. Die Umfrage-Designs bringen dagegen deutsche Texte für Befragte mit (z. B. Fehlermeldungen und Navigation), und Ihre Umfragen selbst können in jeder von LimeSurvey unterstützten Sprache laufen.

Kann ich LimeControl auf meinem eigenen Server betreiben?

Ja. Das Docker-Kit im Verzeichnis deploy/selfhost betreibt die App ohne Google-Konto und ohne Firebase — Sie melden sich mit einem Zugangsschlüssel an, und die Serverprofile bleiben im Browser. Installationsanleitung.

Ich habe keinen LimeSurvey-Server. Können Sie beim Einrichten helfen?

Ja. Sie können unseren offenen Docker-Stack nutzen oder uns Einrichtung und Betreuung einer Umfrageumgebung auf Basis der Software LimeSurvey überlassen — mit HTTPS, Backups und einer für LimeControl vorbereiteten API.

Muss ich ein Plugin in LimeSurvey installieren?

Nein. LimeControl nutzt die eingebaute RemoteControl-2-API — aktivieren Sie einfach die JSON-RPC-Schnittstelle in den globalen Einstellungen. Die Umfrage-Designs und die StrefaAnkiet-Plugins sind optional.

Funktioniert es mit LimeSurvey Cloud und mit einem selbst gehosteten Server?

Ja — mit jeder Instanz 3.x–7.x, die JSON-RPC aktiviert hat und über HTTPS erreichbar ist. Für Server ohne CORS-Header gibt es den Modus Server-Relay.

Unterstützt LimeControl CATI- und CAPI-Studien?

Die kostenlosen Werkzeuge umfassen Interviewer-Designs, Interviewgerüste, die CAPI-Interview-Schleife in der App und die StrefaAnkiet-Plugins. Interviewer-Zuteilungen, Anrufwarteschlange, VoIP-Telefonie und modusübergreifende Quoten bietet ein kostenpflichtiges Konto auf der Plattform StrefaAnkiet.

Wie importiere ich eine Umfragevorlage?

Öffnen Sie in der App den Tab Surveys und wählen Sie „Template library“ — der Import legt eine inaktive Umfrage in der verbundenen Instanz an. Sie können die .lss-Dateien auch von der Website herunterladen und im LimeSurvey-Admin-Panel importieren.

Ich sehe einen CORS-Fehler. Was tun?

Fügen Sie auf dem LimeSurvey-Server CORS-Header hinzu oder stellen Sie das Profil auf den Modus „Server-Relay“ um. Anleitung mit Beispielen für Apache und Nginx.

Wie installiere ich die App auf dem Smartphone?

Installieren Sie die kostenlose mobile App LimeControl. Kostenlos erhältlich: Google Play. Die Version im App Store wartet noch auf die Veröffentlichung. Lieber ohne Store? Installieren Sie die PWA: unter Android über die Schaltfläche „Install PWA“ oder im Chrome-Menü → „Zum Startbildschirm hinzufügen“, auf dem iPhone in Safari über „Teilen“ → „Zum Home-Bildschirm“.
