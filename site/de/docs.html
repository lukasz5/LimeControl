LimeControl — die Anleitung

LimeControl ist eine App zur Verwaltung von LimeSurvey-Instanzen über die offizielle RemoteControl 2-API (JSON-RPC, remotecontrol_handle). Sie läuft als native mobile App für iOS und Android (ohne Konto und ohne CORS-Einschränkungen), im Browser auf Smartphone oder Computer — auch installiert als PWA — und auf Ihrem eigenen Server. Überall ist es derselbe Code.

Voraussetzungen: LimeSurvey 3.x, 5.x, 6.x oder 7.x mit aktivierter JSON-RPC-Schnittstelle und ein LimeSurvey-Konto mit den passenden Berechtigungen. Im Dienst app.limecontrol.eu melden Sie sich mit einem Google-Konto an; eine selbst gehostete Installation nutzt einen Zugangsschlüssel.

Sprache der App: Die Oberfläche von LimeControl gibt es auf Englisch und Polnisch. Bezeichnungen von Schaltflächen und Tabs stehen in dieser Anleitung daher auf Englisch, so wie Sie sie in der App sehen (z. B. Instances, Surveys).

Die App gehört zu einem Open-Source-Werkzeugkasten, der außerdem Umfrage-Designs, Umfragevorlagen und Deployment-Kits umfasst. In dieser Anleitung beschriebene App-Version: 1.1.0.

Schnellstart

  1. Aktivieren Sie im LimeSurvey-Admin-Panel die JSON-RPC-Schnittstelle (Anleitung).
  2. Öffnen Sie app.limecontrol.eu und melden Sie sich mit einem Google-Konto an — oder installieren Sie die mobile App, die ohne Konto auskommt.
  3. Legen Sie im Tab Instances ein Profil an: einen Namen, die Serveradresse (z. B. genügt https://umfragen.ihrefirma.de), den Benutzernamen und das Passwort.
  4. Klicken Sie auf Connect. Die App lädt den Namen der Instanz und die Liste der Umfragen.
  5. Wechseln Sie in den Tab Surveys. Ist die Instanz leer, importieren Sie Ihre erste Umfrage aus der Vorlagenbibliothek.

Bei einem Verbindungsfehler prüfen Sie das Panel RPC log und den Abschnitt CORS und HTTPS.

Installation auf dem Smartphone

Mobile App: die kostenlose App LimeControl für iPhone, iPad und Android. Kostenlos erhältlich: Google Play. Die Version im App Store wartet noch auf die Veröffentlichung. Details im Abschnitt Mobile App.

PWA: Die Web-Version lässt sich ohne App-Store installieren und aktualisiert sich selbst.

  • Android (Chrome, Edge): die Schaltfläche Install PWA in der App oder das Browsermenü → Zum Startbildschirm hinzufügen.
  • iPhone / iPad (Safari): Teilen → Zum Home-Bildschirm.
  • Desktop (Chrome, Edge): das Installationssymbol in der Adressleiste.

Ist das Gerät offline, zeigt die App einen Offline-Hinweis. Umfrageoperationen brauchen Zugriff auf den LimeSurvey-Server.

Die Oberflächensprache (Englisch oder Polnisch) wechseln Sie im Kopfbereich der App; die Wahl wird auf dem Gerät gespeichert.

API in LimeSurvey aktivieren

  1. Melden Sie sich als Superadministrator im LimeSurvey-Admin-Panel an.
  2. Öffnen Sie Konfiguration → Globale Einstellungen → Schnittstellen (engl. Configuration → Global settings → Interfaces).
  3. Wählen Sie im Feld RPC-Schnittstelle aktiviert (RPC interface enabled) den Wert JSON-RPC.
  4. Die Option API unter /admin/remotecontrol veröffentlichen ist nicht erforderlich — setzen Sie sie gemäß Ihrer Sicherheitsrichtlinie. Klicken Sie auf Speichern.

Die Standardadresse der API:

# sprechende URLs aktiviert
https://ihre-instanz.de/index.php/admin/remotecontrol

# sprechende URLs deaktiviert
https://ihre-instanz.de/index.php?r=admin/remotecontrol

In der App genügt die Basisadresse — der Pfad /index.php/admin/remotecontrol wird automatisch ergänzt.

Verbindungsmodi

Jedes Instanzprofil hat seinen eigenen Verbindungsmodus:

Direkt (Standard)

Der Browser sendet JSON-RPC-Anfragen direkt an den LimeSurvey-Server. Es laufen keine Daten über die Server von LimeControl. Voraussetzung sind HTTPS und CORS-Header auf der LimeSurvey-Seite.

Server-Relay

Wenn Sie die Konfiguration des LimeSurvey-Servers nicht ändern können, wählen Sie im Profil Server relay (CORS workaround). Anfragen gehen dann an /api/rpc-relay auf dem App-Server und von dort an LimeSurvey.

  • Das Relay funktioniert nur für angemeldete Nutzer und hat ein Anfragelimit.
  • Es verbindet sich nur über HTTP/HTTPS, folgt keinen Weiterleitungen und lehnt im öffentlichen Dienst interne Netzadressen ab (localhost, 10.x, 192.168.x usw.).
  • In einer selbst gehosteten Installation sind private Adressen standardmäßig erlaubt — LimeSurvey darf im selben Netz liegen.

Im Relay-Modus laufen Benutzername, Passwort und Umfragedaten über den App-Server (gespeichert werden sie dort nicht). Nutzen Sie ihn nur, wenn der Direktmodus nicht möglich ist.

Native App

Die mobile App LimeControl verbindet sich über die native Netzwerkschicht des Systems mit dem Server. Sie unterliegt daher keinen CORS-Einschränkungen und braucht kein Relay.

CORS und HTTPS

Die App läuft über HTTPS, also muss auch der LimeSurvey-Server über HTTPS erreichbar sein — Browser blockieren Anfragen an http://-Adressen (Mixed Content).

Außerdem muss der Server CORS-Header zurückgeben, auch für OPTIONS-Preflight-Anfragen. Statt * können Sie die konkrete App-Domain eintragen.

Apache (.htaccess oder VirtualHost)

Header always set Access-Control-Allow-Origin "https://app.limecontrol.eu"
Header always set Access-Control-Allow-Methods "POST, OPTIONS"
Header always set Access-Control-Allow-Headers "Content-Type, Accept"

Nginx

add_header Access-Control-Allow-Origin "https://app.limecontrol.eu" always;
add_header Access-Control-Allow-Methods "POST, OPTIONS" always;
add_header Access-Control-Allow-Headers "Content-Type, Accept" always;

Haben Sie keinen Zugriff auf die Serverkonfiguration, nutzen Sie den Modus Server-Relay oder die mobile App.

LimeSurvey 7.x

Wählen Sie im Profilformular die Version LimeSurvey 7.x (UTC dates + new error codes) (die Option Automatic behält das Standardverhalten von RC2 bei). Die App dann:

  • rechnet die Daten startdate und expires sowie die Zeiten des Zeitplaners in UTC um,
  • erkennt die neuen Fehlercodes von RemoteControl 2 und zeigt verständliche Meldungen,
  • verarbeitet die neuen Feldbezeichner im get_fieldmap-Inspektor.

Ab LimeSurvey 7.9 können Sie in application/config/config.php ein serverseitiges Protokoll der API-Aufrufe aktivieren:

'config' => array(
    'rpc_log' => true,
)

Das Protokoll landet in tmp/runtime/remotecontrol.log; Passwörter und Sitzungsschlüssel werden darin maskiert.

Instanzen

Der Tab Instances enthält die Profile der LimeSurvey-Server. Im Dienst app.limecontrol.eu liegen die Profile in der Cloud (Cloud Firestore) und sind an Ihr Google-Konto gebunden, also auf jedem Gerät verfügbar. In der mobilen App und in einer selbst gehosteten Installation bleiben die Profile auf dem Gerät bzw. im Browser.

  • Profile nach Name, Adresse, Benutzer oder Login-Plugin durchsuchen und nach Verbindungsmodus filtern (All, Direct, Relay).
  • Eine LimeSurvey-Versionseinstellung je Profil.
  • RPC log — eine Liste der API-Aufrufe mit Antwortzeiten und Fehlerdiagnose (z. B. CORS).

Umfragen

Eine Umfrageliste mit Suche und dem Filter All / Active / Inactive. Über das Schnellmenü neben jeder Umfrage können Sie:

  • eine Umfrage aktivieren (activate_survey), optional zusammen mit ihrer Token-Tabelle (activate_tokens),
  • den Verfügbarkeitszeitraum festlegen — Start- und Enddatum (set_survey_properties),
  • eine aktive Umfrage beenden,
  • eine Umfrage kopieren (copy_survey),
  • zum Zeitplan oder zu den Teilnehmern der gewählten Umfrage springen.

In den Umfragedetails finden Sie außerdem die Karten Link, CAPI-Modus und Design sowie CATI-/CAPI-Feldarbeit.

Vorlagenbibliothek

Die Schaltfläche Template library im Tab Surveys öffnet eine Liste fertiger Fragebögen — dieselben, die Sie auf der Seite Umfragevorlagen herunterladen können. Jede Vorlage enthält eine englische und eine polnische Sprachversion, Bedingungslogik sowie Einladungs- und Erinnerungstexte.

  1. Verbinden Sie sich mit einer Instanz und öffnen Sie Surveys → Template library.
  2. Grenzen Sie die Liste nach Kategorie ein. Jede Vorlage zeigt ihre Erhebungsmodi (CAWI, CATI, CAPI), die Zahl der Fragen, die geschätzte Bearbeitungszeit und das vorgeschlagene Design.
  3. Klicken Sie auf Import. Die App sendet die Strukturdatei .lss mit der Methode import_survey; in der Instanz erscheint eine neue, inaktive Umfrage, die sofort in der Liste ausgewählt ist.
  4. Passen Sie die Fragen im LimeSurvey-Admin-Panel an und aktivieren Sie die Umfrage dann in der App.
  • Die Vorlagen sind in der App enthalten, daher funktioniert die Bibliothek auch in einer selbst gehosteten Installation ohne Internetzugang.
  • Vor dem Import prüft die App die SHA-256-Prüfsumme der Datei gegen den Vorlagenkatalog.
  • Eine Vorlage verweist auf ein LimeControl-Design (z. B. lc_professional). Ist das Design nicht installiert, verwendet LimeSurvey sein Standarddesign — Sie können es später in der Karte Link, CAPI-Modus und Design ändern.
  • Das Konto braucht die Berechtigung, Umfragen zu erstellen.
  • Eine deutsche Fassung ergänzen Sie nach dem Import in LimeSurvey als zusätzliche Sprache.

Die Vorlagen stehen unter CC0 1.0 — Sie dürfen sie frei ändern und nutzen, auch kommerziell.

Link, QR-Code und Design

Die Karte Link, CAPI mode and theme in den Umfragedetails bündelt, wofür Sie sonst das Admin-Panel öffnen würden.

Link für Befragte

  • Die öffentliche Adresse der Umfrage in der gewählten Sprache — mit den Schaltflächen Copy link, Share (das Teilen-Menü des Systems auf dem Smartphone) und Open.
  • Der QR-Code wird im Browser erzeugt; die Adresse wird an keinen externen Dienst gesendet. Scannen Sie ihn mit dem Smartphone oder setzen Sie einen Screenshot auf ein Plakat oder eine Folie.
  • Bei einer inaktiven Umfrage erinnert die App daran, dass der Link erst nach der Aktivierung funktioniert.

Design der Umfrage

Wählen Sie eines der LimeControl-Designs und klicken Sie auf Save theme. Die App setzt die Eigenschaft template und liest sie sofort zurück — ist das Design auf dem Server nicht installiert, nennt eine Meldung das Design, das die Umfrage tatsächlich nutzt.

Die Designs müssen zuerst in LimeSurvey installiert sein: Konfiguration → Designs, Schaltfläche Hochladen & installieren (Anleitung).

CATI- und CAPI-Interviews

LimeControl hilft, eine Umfrage für Interviewer vorzubereiten — am Telefon (CATI) oder im Feld (CAPI). Fragebogen und Antworten bleiben in LimeSurvey.

CAPI-Modus in der App

  • Start an interview öffnet die Umfrage mit dem Parameter newtest=Y, also immer als neues, leeres Interview — ohne die Antworten der vorherigen befragten Person.
  • Switch on the interview loop setzt in der Umfrage die automatische Weiterleitung (autoredirect) und die End-URL jeder Sprachversion so, dass nach jedem Interview von selbst das nächste beginnt. Praktisch für Interviewer und für Kiosk-Stationen.
  • Dieselbe Schaltfläche schaltet die Schleife wieder aus; die App stellt dann das normale Umfrageende wieder her.

Der CAPI-Modus der App braucht eine Internetverbindung — das Interview läuft in der LimeSurvey-Umfrage. Offline-Arbeit bietet die Interviewer-App der Plattform StrefaAnkiet, die die kostenlosen Plugins mit LimeSurvey verbinden.

Interviewer-Designs

  • LimeControl CATI — ein breites Layout für Bildschirm und Tastatur mit Tastenkürzeln: 1–9 und 0 wählen die aufeinanderfolgenden Antworten, Strg+Enter geht zur nächsten Seite, Strg+Umschalt+Enter zurück. Die Kürzel lassen sich mit dem Schalter neben der Navigation abschalten.
  • LimeControl CAPI — größere Schrift und Touch-Flächen von mindestens 56 px Höhe, Navigation fest am unteren Bildschirmrand.
  • In jedem LimeControl-Design wird eine Frage mit der CSS-Klasse lc-interviewer als vorzulesender Text oder vom Interviewer auszufüllendes Feld markiert (zum Interviewer-Modus).

Interviewgerüste

Die Vorlagenbibliothek enthält zwei Gerüste zum Ausbauen:

  • CATI-Interview — Einleitungsskript, Kontaktergebnis (Interview, Rückruf, Verweigerung), Einwilligung, ein Frageblock, Demografie und Interviewernotizen. Mit Teilnehmerfeldern (Telefon, Kontaktstatus, Rückrufzeit, Notiz), die die App zusammen mit der Teilnehmertabelle anlegt (Teilnehmer).
  • CAPI-Interview — Interviewdaten (Interviewer, Sampling Point, Ort), Einwilligung und Screening, ein Frageblock mit Ranking, Demografie und die Beobachtungen des Interviewers nach dem Gespräch.

Interviewer-Zuteilungen, Anrufwarteschlange, VoIP-Telefonie, Rückrufe und modusübergreifende Quoten bietet die Plattform StrefaAnkiet. Die kostenlosen Plugins verbinden sie mit LimeSurvey, und der Feldstatus erscheint in der Karte CATI-/CAPI-Feldarbeit.

Statistiken und Export

Jede Umfrage hat eine Übersicht über Antworten und Tokens (get_summary) mit Diagrammen, und zwei Umfragen lassen sich direkt vergleichen.

Antworten werden exportiert (export_responses) als:

  • CSV — für Tabellenkalkulationen und Analysewerkzeuge,
  • Excel (.xls),
  • JSON — zur Weiterverarbeitung.

Der Spalteninspektor (get_fieldmap) zeigt, wie die Felder im Export heißen — sowohl im älteren SGQA-Format als auch im neuen Format von LimeSurvey 7.

Zeitplaner

Planen Sie eine Operation für einen bestimmten Tag und eine Uhrzeit. Der Auftrag wird vom App-Server ausgeführt und läuft daher auch, wenn Sie die App auf dem Smartphone schließen.

OperationWas der Server tut
Umfrage aktivierenactivate_survey, optional activate_tokens sowie Start- und Enddatum (set_survey_properties)
Umfrage beendensetzt das Enddatum expires auf den Zeitpunkt der Ausführung
Einladungen sendeninvite_participants — an Teilnehmer, die noch keine Einladung erhalten haben
Erinnerungen sendenremind_participants — an eingeladene Teilnehmer, die die Umfrage nicht abgeschlossen haben

Jeder Auftrag beginnt mit get_session_key und endet mit release_session_key:

get_session_key
  → activate_survey        # oder set_survey_properties / invite_participants / remind_participants
  → activate_tokens        # optional, bei der Aktivierung
  → set_survey_properties  # optional: startdate, expires
  → release_session_key

Einladungen und Erinnerungen

  • Die Umfrage muss aktiv sein und eine Teilnehmertabelle haben. LimeSurvey versendet Nachrichten in Paketen — der Server wiederholt den Aufruf, bis die Warteschlange leer ist.
  • Für Erinnerungen legen Sie die Mindestzahl an Tagen seit der letzten Nachricht und die Höchstzahl an Erinnerungen pro Person fest.
  • Repeat every (days) und Number of repeats erzeugen eine Erinnerungsserie: Nach einem erfolgreichen Lauf stellt der Server den nächsten Auftrag ein.
  • Wurde gar keine Nachricht verschickt (z. B. wegen einer fehlerhaften SMTP-Konfiguration in LimeSurvey), endet der Auftrag mit einem Fehler, nicht mit „Erfolg“.

So arbeitet die Warteschlange

  • Die Warteschlange wird alle 15 Sekunden geprüft.
  • Jeder Auftrag hat ein detailliertes Protokoll seiner RPC-Schritte.
  • Run now führt einen Auftrag sofort aus — praktisch zum Testen.
  • Ein geplanter Auftrag lässt sich abbrechen oder aus dem Verlauf entfernen.
  • Das für die Anmeldung nötige Passwort liegt verschlüsselt (AES-256-GCM) in der Warteschlange und wird gelöscht, sobald der Auftrag gelaufen ist oder abgebrochen wurde. Eine Erinnerungsserie behält es bis zur letzten Wiederholung.
  • Die Uhrzeit wird mit der Zeitzone Ihres Geräts gespeichert; für Profile mit LimeSurvey 7.x werden Daten in UTC an den Server gesendet.

Eine Benachrichtigung in der App meldet das Ergebnis eines Auftrags (Erfolg oder Fehler).

Teilnehmer und E-Mail-Vorlagen

Teilnehmer (Tokens)

  • Token-Tabelle mit einem Tippen initialisieren (activate_tokens).
  • Definiert die Umfrage zusätzliche Teilnehmerfelder — wie die Vorlage „CATI-Interview“ —, setzen Sie das Häkchen bei Create the fields from the template, und die App legt sie zusammen mit der Tabelle an.
  • Eine Teilnehmerliste mit Filter für ungenutzte Tokens.
  • Befragte hinzufügen und entfernen.

Vorlageneditor

Bearbeiten Sie Betreff und Text von Einladung und Erinnerung für jede Umfragesprache. Der Editor zeigt eine Vorschau mit Beispieldaten und fügt Platzhalter schnell ein:

{FIRSTNAME} {LASTNAME} {EMAIL} {TOKEN} {SURVEYURL} {OPTOUTURL} {SURVEYNAME}

Die Schaltflächen Save and send invitations und Save and send reminders speichern die Vorlage und versenden sofort die Einladungen (invite_participants) bzw. Erinnerungen (remind_participants). Danach zeigt die App, wie viele Nachrichten verschickt wurden, wie viele fehlgeschlagen sind und wie viele noch warten. Für einen Versand zu einem festen Zeitpunkt nutzen Sie den Zeitplaner.

E-Mails werden über die Mail-Konfiguration Ihres LimeSurvey-Servers verschickt. Prüfen Sie sie in LimeSurvey vor dem ersten Versand.

StrefaAnkiet-Connector (Beta)

Ist eine Umfrage mit einer Studie auf der Plattform StrefaAnkiet verknüpft (über die kostenlosen Plugins für LimeSurvey), zeigt die Karte CATI / CAPI fieldwork in den Umfragedetails den Feldstatus — ohne das Plattform-Panel zu öffnen. Connector und Plugins sind kostenlos; Sie brauchen ein StrefaAnkiet-Konto, das ein kostenpflichtiger Dienst ist.

  1. Erstellen Sie in StrefaAnkiet einen Zugangsschlüssel mit den Scopes fieldwork.read und cati.read: Einstellungen → Integrationszentrum → Zugriff externer Anwendungen.
  2. Öffnen Sie in LimeControl die Umfrage, klappen Sie die Karte CATI / CAPI fieldwork auf und geben Sie die Plattformadresse (z. B. https://app.example.com) und den Schlüssel ein.
  3. Klicken Sie auf Connect and find the study. Die App sucht die mit der Umfrage-ID (SID) verknüpfte Studie. Findet sie keine, geben Sie Projekt- und Studiennummer von Hand ein.
ModusWas die App zeigt
CAPIIn LimeSurvey bestätigte Interviews, Interviews aus der Interviewer-App, Interviewer-Zuteilungen und ihr Fortschritt gegenüber dem Ziel, Hindernisse in der Feldarbeit
CATIDie Zahl der Fälle in der Warteschlange, nicht zugeteilte Fälle und Fälle, die Aufmerksamkeit brauchen
  • Nur lesend. Der Connector ändert nichts an der Studie. Anfragen laufen über den App-Server (/api/strefaankiet), der nur Leseanfragen an eine kurze Liste von API-Adressen der Plattform durchlässt.
  • Der Schlüssel bleibt bei Ihnen. Er liegt nur im Speicher des geöffneten Tabs und verschwindet beim Schließen; der Server speichert und protokolliert ihn nicht. Der Browser merkt sich nur die Plattformadresse und die Verknüpfung von Umfrage und Studie.
  • Die Zuteilungsliste erfordert einen Schlüssel mit der Rolle Studienkoordinator.

Der Connector ist in der Beta: Er wurde gegen die API der Plattform geprüft, aber nicht in jeder Studienkonfiguration. Feedback bitte in den GitHub-Issues.

Mobile App

LimeControl für iOS (iPhone und iPad) und Android ist dieselbe App in einer nativen Hülle — kostenlos und Open Source. Kostenlos erhältlich: Google Play. Die Version im App Store wartet noch auf die Veröffentlichung.

  • Kein Konto. Sie melden sich weder mit einem Google-Konto noch mit einem Zugangsschlüssel an. Serverprofile werden nur auf dem Gerät gespeichert, und die App speichert nie LimeSurvey-Passwörter.
  • Direkte Verbindung. Die App verbindet sich vom Gerät aus mit dem LimeSurvey-Server, ohne CORS-Header und ohne Relay.
  • Teilen und Export. Der Umfragelink und die Ergebnisdateien gehen an das Teilen-Menü des Systems — speichern Sie sie auf dem Gerät oder senden Sie sie weiter.
  • Verschlüsselung. Unter Android muss der Server über HTTPS erreichbar sein. Unter iOS ist eine unverschlüsselte Verbindung nur zu Adressen im lokalen Netz erlaubt.
  • Erscheinungsbild. Die App folgt dem hellen oder dunklen Modus des Systems, bis Sie mit dem Schalter im Kopfbereich selbst wählen.

Der Zeitplaner in der mobilen App

Geplante Aufträge führt ein Server aus, und die mobile App hat keinen eigenen. Wenn Sie ein selbst gehostetes LimeControl betreiben, verbinden Sie es im Tab Instances → Server: erst die Serveradresse, dann den Zugangsschlüssel eingeben. Der Tab Schedule funktioniert dann wie im Browser, und Aufträge laufen auch bei ausgeschaltetem Smartphone. Die Instanzprofile bleiben weiterhin auf dem Gerät.

Der Dienst app.limecontrol.eu (Google-Anmeldung) wird in der mobilen App noch nicht unterstützt.

LimeControl auf dem eigenen Server

Sie können die App selbst in einem Docker-Container betreiben — ohne Google-Konto und ohne Firebase. Sie melden sich mit einem Zugangsschlüssel an, die Instanzprofile werden im Browser gespeichert, und Zeitplaner und Relay laufen in Ihrem Container.

Dienst app.limecontrol.euSelbst gehostete Installation
AnmeldungGoogle-KontoZugangsschlüssel
InstanzprofileCloud Firestore, zwischen Geräten synchronisiertBrowserspeicher, ohne Passwörter
ZeitplanerServer des DienstesIhr Container, Passwörter verschlüsselt im Datenvolume
RPC-Relaynur öffentliche Adressenauch private Netze

Schnellstart

git clone https://github.com/lukasz5/LimeControl.git
cd LimeControl/deploy/selfhost
cp .env.example .env
# eigenen Schlüssel eintragen (mind. 16 Zeichen), z. B. die Ausgabe von: openssl rand -base64 24
nano .env
docker compose up -d --build

Die App läuft unter http://127.0.0.1:8080. Lassen Sie LIMECONTROL_ACCESS_KEY leer, wird beim ersten Start ein Schlüssel erzeugt — lesen Sie ihn mit docker compose logs app aus. Veröffentlichen Sie die App dann über Ihren Reverse Proxy mit TLS-Zertifikat.

Außerhalb von localhost verwenden Sie HTTPS. Ohne HTTPS installiert der Browser die PWA nicht, und Zugangsschlüssel und Passwörter würden im Klartext übertragen.

Neben dem LimeSurvey-Stack

Läuft LimeSurvey mit dem Kit limesurvey-stack, kann LimeControl denselben Traefik und dieselben Let's-Encrypt-Zertifikate nutzen:

# in .env LIMECONTROL_DOMAIN setzen, und STACK_NAME, falls Sie den Stack umbenannt haben
docker compose -f compose.yaml -f compose.with-stack.yaml up -d --build

Fügen Sie in LimeControl eine Instanz mit der Adresse http://limesurvey:8080 und dem Modus Server relay hinzu — die Anfragen bleiben dann im Docker-Netz. Ist in LimeSurvey HTTPS erzwingen aktiviert, verwenden Sie die öffentliche https://-Adresse der Instanz.

Eigene LimeSurvey-Instanz

Haben Sie noch keinen LimeSurvey-Server, nutzen Sie den fertigen, gehärteten Docker-Stack: limesurvey-stack (LimeSurvey 7, PHP 8.3.37, MariaDB 11.4, Traefik mit Let's Encrypt, tägliches Backup).

git clone https://github.com/lukasz5/limesurvey-stack.git
cd limesurvey-stack
sudo ./install.sh

Aktivieren Sie nach der Installation JSON-RPC (API aktivieren) und fügen Sie die Instanz in LimeControl hinzu. Das Installationsprogramm führt Sie im Terminal durch die Konfiguration; ein erneutes sudo ./install.sh öffnet ein Verwaltungsmenü (Backup, Wiederherstellung, Logs, Updates). Details stehen im README des Stacks.

Lieber erledigen lassen? Wir richten Umfrageserver ein und betreuen sie — auf Basis der Software LimeSurvey. Schreiben Sie an info@strefabadan.pl oder nehmen Sie über strefabadan.pl Kontakt auf.

Sicherheit und Datenschutz

  • Google-Anmeldung (Firebase Authentication) schützt den Zugriff auf Ihre Profile; in einer selbst gehosteten Installation übernimmt das ein Zugangsschlüssel mit begrenzten Anmeldeversuchen.
  • Serverprofile liegen in Cloud Firestore; die Datenbankregeln erlauben nur dem Kontoinhaber, sie zu lesen und zu ändern. In der mobilen App und in einer selbst gehosteten Installation bleiben die Profile auf dem Gerät bzw. im Browser.
  • LimeSurvey-Passwörter werden nicht gespeichert — weder in Firestore noch in localStorage. Die Option „Remember the password for this session only“ hält sie ausschließlich im Speicher des geöffneten Tabs.
  • Direktmodus — Umfragedaten gehen direkt vom LimeSurvey-Server in Ihren Browser.
  • Relay und StrefaAnkiet-Connector erfordern eine Anmeldung, haben Anfragelimits, verbinden sich nur über HTTP/HTTPS, folgen keinen Weiterleitungen und fixieren die geprüfte IP-Adresse (Schutz vor SSRF und DNS-Rebinding).
  • Zeitplaner — das zum Ausführen eines Auftrags nötige Passwort wird verschlüsselt (AES-256-GCM) und nur so lange auf dem App-Server gehalten, bis der Auftrag gelaufen ist oder abgebrochen wurde.

Die Datenschutzerklärung beschreibt, welche Daten wir verarbeiten und warum. Sicherheitslücken melden Sie bitte vertraulich — wie, erklärt die Datei SECURITY.md im Repository.

404 oder eine HTML-Antwort statt JSONDie JSON-RPC-Schnittstelle ist deaktiviert oder die API-Adresse weicht ab — geben Sie den vollen Pfad mit ?r=admin/remotecontrol an.
