App features

Everything you need in the field and on the go

The most common survey operations — a few taps away, on any device.

Many LimeSurvey instances

Save a profile for every server and switch between them with one tap. Profiles sync in the cloud once you sign in with a Google account.

Activating and closing surveys

Activate a survey together with its token table, set the startdate and expires dates, close a study or copy a survey.

Server-side scheduler

Schedule an activation, a survey closing, an invitation mailing or recurring reminders. The job runs on the server — even when your phone is off.

Survey template library

Import a ready-made questionnaire into the connected instance with one tap — from NPS to a CATI interview skeleton. You get an inactive survey you can change freely.

Link, QR code and theme

Copy or share the survey link, show a QR code for a poster or a slide, and set the survey theme — without opening the admin panel.

CAPI mode

Start an interview on a tablet or phone and switch on the interview loop: when one interview ends, the survey starts the next, empty one by itself.

Participants and invitations

Add and remove respondents, edit email templates with a live preview, and send invitations and reminders — right away or from the scheduler.

Statistics and comparisons

A summary of responses and tokens in charts, and two surveys compared side by side — all from get_summary.

Response export

Download responses as CSV, Excel or JSON and look up column identifiers (SGQA and LS 7) in the get_fieldmap inspector.

Notifications and RPC log

Messages about completed and failed jobs, a view of every JSON-RPC call with its response time, CORS diagnostics and readable API errors.

How it works

Ready in four steps

You install nothing on the LimeSurvey server — an enabled JSON-RPC API is all it takes.

  1. Enable the API in LimeSurvey

    Configuration → Global settings → Interfaces and choose JSON-RPC.

  2. Sign in

    Open LimeControl and sign in with a Google account. On your own installation an access key is enough.

  3. Add an instance

    Enter the LimeSurvey address, user name and password. The API path is filled in automatically.

  4. Manage

    Activate surveys, import templates, schedule mailings and download results.

CATI and CAPI

Telephone and face-to-face interviews in LimeSurvey

The free LimeControl tools get a survey ready for an interviewer: a comfortable theme, a ready-made interview skeleton and an “interview after interview” mode. When a study needs assignments, a call queue, telephony and quotas, you add the free plugins and a StrefaAnkiet platform account — and follow fieldwork progress in the app.

Free StrefaAnkiet plugins How to run interviews
  • CATI theme — a layout for an interviewer at a computer: answers with the 1–9 keys, next page with Ctrl+Enter, navigation always at hand.
  • CAPI theme — large touch targets and clear typography for a tablet or phone in the field.
  • Interview skeletons — the “CATI interview” (call outcome, callback time, interviewer note) and “CAPI interview” templates, in English and Polish.
  • Interview loop — the app sets the survey up so that it starts the next interview by itself when one ends; the link and QR code for the interviewer are at hand.
  • Fieldwork status from StrefaAnkiet — completed interviews, interviewer assignments and the call queue next to the survey, read-only (beta).

Security and privacy

Your passwords stay with you

In direct mode LimeControl talks to your server straight from the browser — survey data does not pass through our servers, and LimeSurvey passwords are not saved in the profiles.

How we protect data
  • LimeSurvey passwords never reach the cloud — neither Firestore nor localStorage. Optionally they are kept only in the memory of the open tab.
  • A direct connection from the browser to your server over HTTPS. You switch the server relay on only when you need it.
  • The relay is for signed-in users only — with a request limit and, in the public service, internal network addresses blocked.
  • The scheduler encrypts the job password (AES-256-GCM) and removes it as soon as the job has run or been cancelled.
  • The code is open — you can review it or run the app on your own server.
FAQ

Frequently asked questions

Is LimeControl free?

Yes. The app, the themes, the survey templates, the plugins and the deployment kits are free of charge — with no limit on surveys or instances. If you find them useful, you can support their development with the “Buy me a coffee” link in the footer.

So what is paid?

Services. A StrefaAnkiet account provides what software alone cannot: managed mailing through Amazon SES, VoIP telephony for CATI interviews, interviewers in the field, and analysis and reports. Separately we offer survey server deployment and maintenance. The free tools work without any of these services.

Is LimeControl open source?

Yes. The code of the app, the survey themes and the deployment kits is on GitHub under GPL-2.0-or-later, and the survey templates are released under CC0. The StrefaAnkiet plugins for LimeSurvey are open source too. Bug reports and pull requests are welcome. The content and design of this website are not part of the open-source code.

Can I run LimeControl on my own server?

Yes. The Docker kit in the deploy/selfhost directory runs the app without a Google account and without Firebase — you sign in with an access key and the server profiles stay in the browser. Installation guide.

I don't have a LimeSurvey server. Can you help me set one up?

Yes. You can use our open Docker stack or let us handle the deployment and maintenance of a survey environment based on LimeSurvey software — with HTTPS, backups and an API ready for LimeControl.

Do I need to install a plugin in LimeSurvey?

No. LimeControl uses the built-in RemoteControl 2 API — just enable the JSON-RPC interface in the global settings. The survey themes and the StrefaAnkiet plugins are optional.

Does it work with LimeSurvey Cloud and with a self-hosted server?

Yes — with any 3.x–7.x instance that has JSON-RPC enabled and is reachable over HTTPS. For servers without CORS headers there is a server relay mode.

Does LimeControl support CATI and CAPI studies?

The free tools cover interviewer themes, interview skeletons, the CAPI interview loop in the app and the StrefaAnkiet plugins. Interviewer assignments, a call queue, VoIP telephony and quotas across modes are provided by a paid StrefaAnkiet platform account.

How do I import a survey template?

In the app, open the Surveys tab and choose “Template library” — the import creates an inactive survey in the connected instance. You can also download the .lss files from the website and import them in the LimeSurvey admin panel.

I see a CORS error. What should I do?

Add CORS headers on the LimeSurvey server or switch the profile to “Server relay” mode. Instructions with examples for Apache and Nginx.

How do I install the app on my phone?

On Android use the “Install PWA” button in the app or the Chrome menu → “Add to Home screen”. On an iPhone, in Safari choose “Share” → “Add to Home Screen”. An app for the App Store and Google Play is on its way.

What permissions does the LimeSurvey account need?

Reading, editing, creating and activating surveys, managing participants and exporting responses. The full list of permissions.
