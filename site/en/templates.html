In every template

More than a list of questions

The templates are generated from readable JSON definitions and built by the same script that validates them. After importing you can change anything in LimeSurvey.

  • Two languages in one file — Polish as the base language and English as an additional one; respondents switch languages on the survey page.
  • Conditional logic — follow-up questions depend on the rating (e.g. a different question for NPS detractors and promoters).
  • Computed fields — the NPS segment and the SUS score (0–100) are stored with the responses, ready for export.
  • Analysis-friendly codes — short question codes and scales with numeric values 1–5 and 0–10.
  • Email texts — invitation, reminder, confirmation and registration in both languages.
  • A matching theme — if the suggested LimeControl theme is installed, the survey uses it straight away; if not, LimeSurvey picks the default theme.
  • Private by default — anonymous responses, no IP addresses or timestamps (except the CATI/CAPI templates, where timing is needed for quality control).
Import

Three ways to import

  1. In the LimeControl app

    Connect to your instance and open Surveys → Template library. Pick a template and tap Import — the survey appears in the list as inactive, ready for editing. Open the app.

  2. In the LimeSurvey admin panel

    Download the .lss file. In the panel choose Surveys → Create survey → Import, select the file and click Import survey.

  3. Through the RemoteControl 2 API

    Call import_survey with the file content encoded in base64 and the type lss. This is how the import in LimeControl and the survey-templates/verify.mjs script in the repository work.

After import the survey is inactive. Fill in the texts in square brackets (company name, study topic), set the administrator and activate it — in the panel or in LimeControl.

CATI and CAPI

Interview skeletons for interviewers

The CATI and CAPI templates include scripts to read out, the call outcome, respondent consent and an interviewer notes block. They look best with the CATI and CAPI themes, which highlight interviewer instructions and keep the navigation buttons at the bottom of the screen.

Participant fields in the CATI template

The template defines four participant attributes: Phone, Contact status, Callback time and Interviewer note. When initialising the participant table in LimeControl, tick “Create fields from the template”.

Interview after interview on a tablet

In LimeControl open the survey in CAPI mode — when an interview is finished the survey starts again, without the previous respondent’s data.

Call queue, assignments and quotas

Full CATI/CAPI fieldwork — a case queue, a VoIP phone, interviewer assignments, quotas and quality control — is provided by a StrefaAnkiet platform account. The free plugins connect it to LimeSurvey.

Questions and answers

May I modify the templates and use them commercially?

Yes. The templates are released under CC0 1.0 — you may copy, change and use them for any purpose, without attribution. The SUS questionnaire was created by John Brooke (1986) and is freely available for use.

Which LimeSurvey versions do they work with?

We tested them on LimeSurvey 6.15.12 and 7.10.0. The files use the survey structure format introduced in LimeSurvey 4, so they should also import in versions 4 and 5 — but we have not tested those.

I only need one language. How do I remove the other?

After importing, open Survey settings → General and remove the language from “Additional languages”. To change the base language, copy the survey and choose a new base language in the copy’s settings.

The imported survey does not use a LimeControl theme

The template names a suggested theme (e.g. lc_medical). If it is not installed, LimeSurvey uses the default theme. Download the themes, install them and select the theme in the survey settings or in LimeControl.

How do I suggest a new template or a fix?

The template definitions are JSON files in the survey-templates/templates directory of the LimeControl repository. Open an issue or send a pull request — the build script validates the file for you.

Import a template from your phone

In LimeControl you pick a template, import it into your instance and activate the survey.
