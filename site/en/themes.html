Survey themes for LimeSurvey

Surveys that everyone can read — on a phone and on a desktop.

Eight free themes for LimeSurvey 6 and 7 built on one tested pattern: large answer fields, a clear focus ring, readable errors and WCAG 2.2 AA contrast. Download the ZIP for your version, import it in the admin panel and you are done. Installation guide.

Accessibility

One shared, tested pattern

All themes share one base stylesheet (lc-base.css) and the lc-a11y.js script. They differ only in colours, typography, corner radii and layout — so they behave the same and are equally accessible.

The contrast of every palette is checked automatically when the packages are built — a theme that misses the thresholds is not released.

  • Contrast of at least 4.5:1 for text and 3:1 for field borders and focus (WCAG 1.4.3, 1.4.11).
  • Visible focus — a 3 px outline with an offset for keyboard navigation (2.4.7, 2.4.13).
  • Touch targets ≥ 44 px; the whole answer tile is clickable (2.5.8).
  • Errors not by colour alone — border, icon and text; focus moves to the first question with an error and the field gets aria-invalid (1.4.1, 3.3.1).
  • Native form controls — they work in Windows high-contrast mode and with screen readers.
  • Reflow — no horizontal scrolling from 320 px; wide tables scroll inside their own container (1.4.10).
  • A “Skip to questions” link, labelled mandatory questions and a named menu button (2.4.1, 4.1.2).
  • Six theme interface languages — English, Polish, German, French, Spanish and Ukrainian; picked from the survey language.
  • User preferences — prefers-reduced-motion, forced-colors, print.
  • GDPR-friendly — system fonts, no CDNs and no tracking scripts.
CATI and CAPI

Interviewer mode in every theme

The CATI and CAPI themes are designed for interviewers, but their mechanisms work in every LimeControl theme. Ready-made questionnaires are in the survey templates; call queues, telephony, assignments and quotas are provided by the StrefaAnkiet platform, which the free plugins connect to LimeSurvey.

Scripts and interviewer fields

Give a question the CSS class lc-interviewer (Question settings → Display → CSS class) and the theme marks it with a dashed frame as text to read out or a field completed by the interviewer.

Sticky navigation

In the CATI and CAPI themes the Back and Next buttons stay at the bottom edge of the screen — also on a phone, where they fit in one row.

Keyboard shortcuts (CATI)

Keys 1–9 select an answer; in arrays the focus moves to the next row by itself. Ctrl+Enter is “Next”, Ctrl+Shift+Enter is “Back”. Shortcuts can be switched off in the navigation bar.

A tablet in the field (CAPI)

20 px text, 56 px touch targets and a black-and-white palette with one strong accent — readable even in bright sunlight.

Installation

Install a theme on your LimeSurvey

You need a superadministrator account (or the permission to import themes) and LimeSurvey 6.x or 7.x with the built-in Fruity TwentyThree theme.

  1. Download the ZIP for your version

    The LimeSurvey version is shown in the footer of the admin panel. Download the 7.x or 6.x variant and do not rename the file — LimeSurvey names the theme directory after the file (e.g. lc_medical).

  2. Upload it to LimeSurvey

    Configuration → Themes, the Survey themes tab, the Upload & install button. Choose the ZIP file and confirm.

  3. Select it in a survey

    In the survey: Survey settings → General → Theme, choose e.g. “LimeControl Medical” and save. In the LimeControl app it takes a single tap.

  4. Add your logo

    In the survey, Theme options → Images: set Logo: Yes and upload a PNG or JPG file.

Why two variants? LimeSurvey 7 added new options to the parent theme (colours, corner radii, icons, table wrapping), and the Theme options form only shows the options described in the package. Look and accessibility are identical in both variants — only the list of options in the panel differs. The 6.x variant is not marked as compatible with LimeSurvey 7 and vice versa.

Manual installation (FTP / SSH)

When uploading through the panel is blocked (e.g. by the upload_max_filesize limit or directory permissions):

# on the server, in the LimeSurvey root directory
mkdir -p upload/themes/survey/lc_medical
unzip lc_medical.zip -d upload/themes/survey/lc_medical

The config.xml file must sit directly in upload/themes/survey/lc_medical/. Then find the theme in the list of available themes in Configuration → Themes and click Install.

Default theme for new surveys

Configuration → Global → General → Default theme. Existing surveys keep their theme — change it in the settings of each survey.

Your own colours and fonts

Open Configuration → Themes → Theme editor for the theme and edit css/lc-theme.css — all colours are --lc-* variables at the top of the file. After changing them, check the contrast (text ≥ 4.5:1, borders ≥ 3:1).

Updating to a new version

LimeSurvey will not overwrite an existing theme on import. The simplest way is to replace the files over FTP in upload/themes/survey/lc_… and then click Clear assets cache in Configuration → Global → General.

Alternatively: Uninstall the theme, delete its directory from the server and import the new ZIP (surveys then have to be assigned to the theme again).

Troubleshooting

“Cannot import a theme that already exists”

A theme with this name is already on the server (the directory stays even after uninstalling). Delete the upload/themes/survey/lc_… directory or update the files manually — see “Updating to a new version”.

The theme has an odd name such as lc_medical_1, or does not work after import

Your browser added “(1)” to the downloaded file. Remove that theme, rename the file back to lc_medical.zip and import it again. The file name must match the name in config.xml (lc_medical, lc_professional, lc_social, lc_marketing, lc_eco, lc_minimalist, lc_cati, lc_capi).

I upgraded LimeSurvey from 6 to 7 — what about the theme?

Replace the theme files with the 7.x variant (over FTP in upload/themes/survey/lc_…), then use Reset next to the theme in Configuration → Themes to load the new list of options, and clear the assets cache. The logo settings then have to be chosen again.

Errors appear in a popup instead of next to the question

The themes show messages on the page by default. If your survey behaves differently, set Theme options → Simple options → Show popups to On page.

“Cannot import the theme because fruity_twentythree is not installed”

The themes extend the built-in Fruity TwentyThree theme available in LimeSurvey 6 and 7. Install it in Configuration → Themes or update LimeSurvey. Versions 5.x and older are not supported.

The survey looks the same after CSS changes

LimeSurvey caches theme files. Click Clear assets cache in Configuration → Global → General and reload the survey page bypassing the browser cache.

How do I switch off keyboard shortcuts in the CATI theme?

Interviewers switch them off with the “Shortcuts” button in the navigation bar (the choice is remembered in the browser). To disable them permanently, remove the line --lc-hotkeys: 1; from css/lc-theme.css.

May I use the themes commercially and modify them?

Yes. The themes are licensed under GPL-2.0-or-later (like LimeSurvey) — you may change them, rebrand them and use them in commercial projects.

Do the themes work with LimeControl?

Yes — a theme is a survey setting on the LimeSurvey side. In the LimeControl app you can assign an installed theme to a survey.
